1Что такое suite

Начнём с самого простого, потому что дальше всё строится на этом.

Suite numérique — это просто пронумерованный список чисел. Первое число, второе, третье и так до бесконечности.

Например: 2, 5, 8, 11, 14, …

Каждое число в списке имеет свой номер. Этот номер называется rang (ранг) или indice (индекс), и его пишут маленькой цифрой внизу:

u0 = 2      u1 = 5      u2 = 8      u3 = 11
Définition

Une suite numérique est une fonction définie sur ℕ (ou sur une partie de ℕ) à valeurs dans ℝ.

По-русски: это функция, у которой на входе может быть только целое неотрицательное число (номер), а на выходе — обычное число.

Обозначения — здесь путаются чаще всего

Notations
ЗаписьЧто это
un Одно число — член с номером n. Называется terme de rang n. Например u3 = 11 — это просто число 11.
(un) Вся последовательность целиком — весь бесконечный список. Скобки обязательны. Часто пишут (un)n∈ℕ.
u(n) То же, что un, просто в «функциональной» записи. Встречается реже, но ты её увидишь, когда учитель захочет подчеркнуть, что suite — это функция.
Piège classique

«Вычислите (un)» — так не говорят. Вычисляют член un. А (un) изучают: она возрастает, убывает, сходится.

Если в задании написано «Montrer que (un) est croissante» — речь про всю последовательность. Если «Calculer u5» — про одно число.

Внимание

Нумерация может начинаться с 0 или с 1 — это решает автор задачи. Всегда смотри на условие. Если написано «u0 = 3», значит отсчёт с нуля, и u5 — это шестой член, а не пятый.

2Два способа задать suite

Это ключевой момент всей темы. Если понять разницу — половина трудностей исчезает.

Чтобы описать бесконечный список чисел, нужно правило. Правил бывает два типа.

Способ A — Forme explicite

Формула напрямую связывает номер и значение: un = f(n).

un = 3n + 2

Подставляешь номер — получаешь член. Сразу, без разгона:

u0 = 3·0 + 2 = 2      u1 = 3·1 + 2 = 5      u100 = 3·100 + 2 = 302

Главное преимущество: можно прыгнуть сразу к u1000, не считая предыдущие.

Способ B — Relation de récurrence

Формула связывает соседние члены: каждый следующий выражается через предыдущий.

u0 = 2   и   un+1 = un + 3

Считать можно только по цепочке, шаг за шагом:

u1 = 2 + 3 = 5  →  u2 = 5 + 3 = 8  →  u3 = 8 + 3 = 11
Почему нужен первый член

Правило «un+1 = un + 3» само по себе бесполезно — оно говорит, как шагать, но не говорит, откуда стартовать. Поэтому задание по рекуррентности всегда включает первый член. Если его нет — условие неполное.

Сравнение

ExpliciteRécurrence

Считаем u50 сразу, одной подстановкой только пройдя все 50 шагов

Ключевая идея

Одну и ту же suite можно задать обоими способами. Те же числа 2, 5, 8, 11 выше описаны и явной формулой, и рекуррентной.

Огромная часть задач Terminale — это перевод из рекуррентной формы в явную. Потому что с явной легко найти предел, а с рекуррентной — нет.

3Как считать члены

Механика, которую нужно довести до автоматизма.

Если форма явная

Exemple

un = n² − 4n + 1. Найти u3.

Везде вместо n пишем 3:

u3 = 3² − 4·3 + 1 = 9 − 12 + 1 = −2
Piège

Если просят un+1, подставляй (n+1) в скобках, всюду:

un+1 = (n+1)² − 4(n+1) + 1 = n² + 2n + 1 − 4n − 4 + 1 = n² − 2n − 2

Классическая ошибка — написать un+1 = un + 1. Это неверно: индекс сдвигается, а не значение.

Если форма рекуррентная

Exemple

u0 = 1, un+1 = 2un + 3. Найти u3.

Идём по цепочке — перепрыгнуть нельзя:

u1 = 2·1 + 3 = 5
u2 = 2·5 + 3 = 13
u3 = 2·13 + 3 = 29
Как не запутаться

В формуле un+1 = 2un + 3 читай так: «новый = 2 × старый + 3». Индексы — это просто «кто новый, кто старый».

4График

Suite — не кривая. Это набор отдельных точек.

Поскольку n принимает только целые значения, график — это отдельные точки, а не линия. По-французски: nuage de points (облако точек).

Точки имеют координаты (n ; un): номер по горизонтали, значение по вертикали.

Erreur fréquente

Соединять точки линией. Между u2 и u3 ничего нет — u2{,}5 не существует. На экзамене за соединённые точки снимают баллы.

Построение «лесенкой» (construction en escalier)

Для рекуррентной suite un+1 = f(un) есть особый приём, который часто просят на экзамене.

  1. Чертим кривую y = f(x) и прямую y = x (биссектрису).
  2. Отмечаем u0 на оси абсцисс.
  3. Идём вертикально до кривой — получаем высоту u1.
  4. Идём горизонтально до биссектрисы — переносим u1 на ось абсцисс.
  5. Повторяем: вертикаль до кривой, горизонталь до биссектрисы.

Получается ступенчатая ломаная. По ней сразу видно, растёт suite или убывает, и к чему она стремится — точка пересечения кривой с биссектрисой и есть предел.

Зачем биссектриса

Она «перекладывает» значение с вертикальной оси на горизонтальную. Мы получили u1 как высоту, а нам нужно вставить его в функцию — то есть положить на горизонтальную ось. Прямая y = x делает ровно это.

5Монотонность — sens de variation

Вопрос «растёт или убывает» — один из самых частых на экзамене.

Définitions

(un) est croissante si pour tout n, un+1 ⩾ un.

(un) est décroissante si pour tout n, un+1 ⩽ un.

(un) est monotone si elle est croissante ou décroissante.

Strictement croissante — если неравенство строгое (> вместо ⩾).

Метод 1 — знак разности (le plus sûr)

Считаем un+1 − un и смотрим на знак.

Если для всех nТо suite
un+1 − un > 0строго возрастает
un+1 − un < 0строго убывает
un+1 − un = 0постоянна
Exemple

un = n² + 2n

un+1 − un = [(n+1)² + 2(n+1)] − [n² + 2n]
= n² + 2n + 1 + 2n + 2 − n² − 2n
= 2n + 3

Для любого n ⩾ 0 получаем 2n + 3 > 0, значит suite строго возрастает.

Метод 2 — частное (si tous les termes sont > 0)

Работает только если все члены строго положительны. Сравниваем un+1 / un с единицей.

Если для всех nТо suite
un+1/un > 1возрастает
un+1/un < 1убывает
Обязательное условие

Перед этим методом напиши в решении, что все члены положительны. Без этой фразы метод недействителен: при делении на отрицательное число знак неравенства переворачивается.

Формулировка для экзамена: «Tous les termes de la suite sont strictement positifs, on peut donc comparer le quotient à 1.»

Метод 3 — через функцию (forme explicite uniquement)

Если un = f(n), изучаем функцию f на промежутке [0 ; +∞[. Если f возрастает там — то и suite возрастает.

Не работает для рекуррентных

Если suite задана как un+1 = f(un), этот метод неприменим. Тут f действует на значение, а не на номер. Очень распространённая ошибка.

6Suites arithmétiques

Первый из двух «именных» типов. Прибавляем одно и то же.

Définition

Une suite (un) est arithmétique s'il existe un réel r tel que pour tout n :

un+1 = un + r

r s'appelle la raison de la suite.

Ложный друг переводчика

raison — это разность, а не «причина» и не «разум». В русских учебниках это d (différence), во французских — r.

Как узнать арифметическую suite

Считаем разность соседних членов. Если она всегда одинаковая — suite арифметическая.

Exemple

7, 11, 15, 19, 23, …

11 − 7 = 4 ;  15 − 11 = 4 ;  19 − 15 = 4 ;  23 − 19 = 4

Разность постоянна, значит suite арифметическая с r = 4.

Внимание на доказательство

Проверить пару членов — недостаточно для доказательства. Нужно посчитать un+1 − un в общем виде и показать, что результат не зависит от n.

Формула общего члена

Чтобы дойти от u0 до un, нужно прибавить r ровно n раз:

un = u0 + n × r

Более общая формула — от любого члена к любому:

un = up + (n − p) × r
Как запомнить

«Сколько шагов между p и n? Ровно (n − p). Каждый шаг добавляет r.»

Если нумерация с единицы, формула становится un = u1 + (n − 1)r. Не заучивай два варианта — выводи из общей.

Монотонность

Здесь всё просто: un+1 − un = r, поэтому знак разности — это знак r.

RaisonSuite
r > 0строго возрастает
r < 0строго убывает
r = 0постоянна

7Suites géométriques

Второй тип. Умножаем на одно и то же.

Définition

Une suite (un) est géométrique s'il existe un réel q non nul tel que pour tout n :

un+1 = q × un

q s'appelle la raison de la suite.

Слово то же, смысл другой

У арифметической raison — это то, что прибавляют. У геометрической — то, на что умножают. Одно слово, две роли. Смотри на тип suite.

Как узнать геометрическую suite

Делим соседние члены. Если частное всегда одинаковое — suite геометрическая.

Exemple

3, 6, 12, 24, 48, …

6/3 = 2 ;  12/6 = 2 ;  24/12 = 2 ;  48/24 = 2

Частное постоянно, значит suite геометрическая с q = 2.

Формула общего члена

Чтобы дойти от u0 до un, умножаем на q ровно n раз:

un = u0 × qn

Общая форма:

un = up × qn − p

Монотонность

Здесь сложнее, чем у арифметической — результат зависит и от q, и от знака первого члена.

При u0 > 0
RaisonSuite
q > 1строго возрастает (взрыв в бесконечность)
q = 1постоянна
0 < q < 1строго убывает (затухает к нулю)
q < 0не монотонна — знак чередуется
Отрицательное q

Если q < 0, члены прыгают: плюс, минус, плюс, минус. Такая suite не возрастает и не убывает. По-французски: la suite n'est ni croissante ni décroissante, elle est alternée.

Если u0 < 0, вся таблица переворачивается. Поэтому в решении всегда указывай знак первого члена.

Как различать в задаче

Ищи ключевые слова в условии:

  • «augmente de 50 € par mois» → прибавляем → arithmétique
  • «augmente de 5 % par an» → умножаем на 1,05 → géométrique

Коэффициент для процентов

Рост на t % → умножение на (1 + t/100). Падение на t % → умножение на (1 − t/100).

9Суммы — sommes de termes

Складываем много членов сразу, не считая каждый.

Легендарная сумма Гаусса

1 + 2 + 3 + … + n = n(n + 1)2
Откуда она берётся

Запишем сумму дважды — вперёд и назад:

1  +  2  +  …  +  (n−1)  +  n
n  +  (n−1)  +  …  +  2  +  1

Складываем по столбцам: каждая пара даёт (n + 1), и таких пар ровно n. Значит удвоенная сумма равна n(n+1), а сама сумма — половина этого.

Сумма арифметической suite

S = (nombre de termes) × premier + dernier2

В формальном виде, для u0 + u1 + … + un:

S = (n + 1) × u0 + un2
Число членов

От u0 до un членов n + 1, а не n. Ноль тоже считается! Это ошибка номер один в этой теме.

Общее правило: от up до un членов (n − p + 1).

Сумма геометрической suite

1 + q + q² + … + qn = 1 − qn+11 − q (si q ≠ 1)

Для произвольной геометрической suite:

S = u0 × 1 − qn+11 − q
Мнемоника

«Первый член × 1 − raisonчисло членов1 − raison»

Показатель в числителе — это количество слагаемых, а не последний индекс. От u0 до un их n+1 — отсюда qn+1.

10Raisonnement par récurrence Terminale

Метод доказательства, который пугает всех, а устроен проще некуда.

Идея домино

Представь бесконечный ряд костяшек домино. Чтобы упали все, нужны две вещи:

  1. Толкнуть первую. Если её не толкнуть, ничего не начнётся.
  2. Гарантия, что каждая падающая роняет следующую. Если между какими-то костяшками разрыв — цепочка оборвётся.

Если оба условия выполнены — упадут все. Это и есть récurrence.

Principe de récurrence

Soit P(n) une propriété dépendant de n. Si :

  • P(0) est vraie (initialisation)
  • pour tout n, P(n) vraie ⟹ P(n+1) vraie (hérédité)

alors P(n) est vraie pour tout n ∈ ℕ.

Шаблон оформления

Это нужно писать дословно. Во Франции за структуру решения дают отдельные баллы — даже если вычисления не доведены до конца.

Rédaction type — выучить наизусть 
Montrons par récurrence que pour tout n ∈ ℕ,
la propriété P(n) : « ... » est vraie.

▸ Initialisation

Pour n = 0 :
   [подставляем 0 и проверяем]
Donc P(0) est vraie.

▸ Hérédité

Supposons que pour un entier n ⩾ 0 fixé, P(n) soit vraie,
c'est-à-dire : [пишем гипотезу]
Montrons alors que P(n+1) est vraie,
c'est-à-dire : [пишем, что хотим получить]

   [вычисления — обязательно используем гипотезу]

Donc P(n+1) est vraie.

▸ Conclusion

P(0) est vraie et P est héréditaire.
D'après le principe de récurrence,
P(n) est vraie pour tout n ∈ ℕ.

Разобранный пример

Exercice type

Soit (un) définie par u0 = 1 et un+1 = 2un + 1.
Montrer que pour tout n, un = 2n+1 − 1.

Initialisation

Pour n = 0 : u0 = 1 (условие) и 20+1 − 1 = 2 − 1 = 1. Совпало, значит P(0) вроде.

Hérédité

Предположим, что для некоторого n верно un = 2n+1 − 1.
Покажем, что un+1 = 2n+2 − 1.

un+1 = 2un + 1   (рекуррентная формула)
= 2(2n+1 − 1) + 1   (подставили гипотезу)
= 2n+2 − 2 + 1
= 2n+2 − 1 ✓

Conclusion

P(0) верно, свойство наследуется — значит по принципу рекуррентности формула верна для всех n.

Три ошибки, которые стоят баллов
  1. Забыть initialisation. Без неё доказательства нет вообще. Домино не толкнули.
  2. Написать «supposons que pour tout n». Нет! Пишем «pour un entier n fixé». Если предположить «для всех», ты предполагаешь то, что доказываешь.
  3. Не использовать гипотезу в hérédité. Если в вычислениях ты ни разу не подставил P(n) — почти наверняка что-то не так. Отметь момент подстановки явно.

11Пределы — limites · Terminale

Куда suite приходит, если идти по ней бесконечно долго.

Интуиция

Вопрос простой: к чему приближаются члены, когда n растёт?

SuiteПоведениеПредел
un = 1/n1 ;  0,5 ;  0,33 ;  0,25 ;  …0
un = n²0 ;  1 ;  4 ;  9 ;  16 ;  …+∞
un = (−1)n1 ;  −1 ;  1 ;  −1 ;  …нет
un = 33 ;  3 ;  3 ;  …3
Vocabulaire

Suite convergente — у неё есть конечный предел L. Пишут: lim un = L или un → L.

Suite divergente — конечного предела нет. Два случая: либо уходит в ±∞, либо болтается без предела, как (−1)n.

Важно

«Divergente» ≠ «уходит в бесконечность». Suite (−1)n ограничена числами −1 и 1, но всё равно divergente — у неё просто нет предела.

Как запомнить

Число по модулю меньше единицы при возведении в степень тает: 0,5 → 0,25 → 0,125 → 0. Число больше единицы разгоняется: 2 → 4 → 8 → ∞.

Если q отрицательное и по модулю больше 1 — знак прыгает, и предела быть не может.

Неопределённости (formes indéterminées)

Четыре ситуации, где «арифметика бесконечностей» не работает и нужно преобразовывать выражение:

«∞ − ∞»      «0 × ∞»      «∞∞»      «00»
Стандартный приём

Вынести за скобку член наибольшего порядка — в числителе и в знаменателе отдельно, потом сократить.

3n² + 2nn² − 5 = n²(3 + 2/n)n²(1 − 5/n²) = 3 + 2/n1 − 5/n² → 31 = 3

Теоремы сравнения

Théorème de comparaison

Si un ⩾ vn à partir d'un certain rang et lim vn = +∞, alors lim un = +∞.

Логика: если тот, кто ниже тебя, улетел в бесконечность, то ты и подавно.

Théorème des gendarmes (теорема о двух милиционерах)

Si vn ⩽ un ⩽ wn et lim vn = lim wn = L, alors lim un = L.

Название буквальное: два жандарма ведут задержанного. Куда идут они — туда и он, деваться некуда.

Théorème de convergence monotone

Toute suite croissante et majorée converge.
Toute suite décroissante et minorée converge.

Растёт, но упирается в потолок — обязана к чему-то прийти. Теорема гарантирует существование предела, но не даёт его значение.

Тонкость

majorée (ограничена сверху) — существует M такое, что все члены ⩽ M.
minorée (ограничена снизу) — существует m такое, что все члены ⩾ m.
bornée — и то, и другое сразу.

12Арифметико-геометрические

Самый частый тип задачи на экзамене. Метод всегда один и тот же.

Suite вида un+1 = a·un + b называется arithmético-géométrique. Она не арифметическая и не геометрическая — но сводится к геометрической одним приёмом.

Алгоритм — три шага
  1. Находим неподвижную точку. Решаем c = a·c + b. Отсюда c = b/(1 − a).
  2. Вводим новую suite vn = un − c и доказываем, что она геометрическая с raison a.
  3. Возвращаемся. Находим vn по формуле геометрической, потом un = vn + c.
Exercice type

u0 = 5, un+1 = 0,5un + 3

Шаг 1 — неподвижная точка

c = 0,5c + 3  ⟹  0,5c = 3  ⟹  c = 6

Шаг 2 — новая suite

Положим vn = un − 6. Тогда:

vn+1 = un+1 − 6 = (0,5un + 3) − 6
= 0,5un − 3 = 0,5(un − 6) = 0,5vn

Значит (vn) геометрическая с raison 0,5 и первым членом v0 = 5 − 6 = −1.

Шаг 3 — возвращаемся

vn = −1 × 0,5n
un = vn + 6 = 6 − 0,5n

Бонус — предел

Так как 0 < 0,5 < 1, имеем 0,5n → 0, значит lim un = 6.

Обрати внимание: предел равен неподвижной точке. Это не совпадение — suite стремится именно к ней.

На экзамене

Обычно suite (vn) дают в условии: «On pose vn = un − 6. Montrer que (vn) est géométrique.» Искать неподвижную точку самому не придётся — но понимать, откуда взялась шестёрка, полезно.

13Типичные ошибки

Собрано по тому, за что реально снимают баллы.

ОшибкаКак правильно
Соединять точки на графике линией Только отдельные точки — nuage de points
Считать, что от u0 до un ровно n членов Их n+1 — ноль тоже считается
un+1 = un + 1 при подстановке Подставлять (n+1) в скобках всюду, где стоит n
Проверить 2–3 члена и объявить suite арифметической Считать un+1 − un в общем виде
Метод частного без проверки знака Сначала написать, что все члены > 0
Изучать f для рекуррентной suite Так можно только для явной формы
Забыть initialisation в récurrence Без неё доказательства не существует
«Supposons que pour tout n…» «Supposons que pour un entier n fixé…»

14Задачи с решениями

Разбирай с закрытым решением, потом сверяйся.

Exercice 1 · arithmétique

(un) arithmétique, u0 = 7, r = −3.
a) Calculer u10.   b) Calculer S = u0 + u1 + … + u10.

Решение

a) u10 = u0 + 10r = 7 + 10×(−3) = 7 − 30 = −23

b) Членов от 0 до 10 ровно 11:

S = 11 × 7 + (−23)2 = 11 × −162 = 11 × (−8) = −88
Exercice 2 · géométrique

(vn) géométrique, v0 = 2, q = 3.
a) Exprimer vn.   b) Calculer v0 + v1 + … + v5.

Решение

a) vn = 2 × 3n

b) Слагаемых 6, значит показатель в формуле — 6:

S = 2 × 1 − 361 − 3 = 2 × 1 − 729−2 = 2 × 364 = 728
Exercice 3 · sens de variation

Étudier le sens de variation de un = nn + 1 pour n ⩾ 0.

Решение

un+1 − un = n + 1n + 2 − nn + 1 = (n+1)² − n(n+2)(n+2)(n+1)

В числителе: n² + 2n + 1 − n² − 2n = 1

un+1 − un = 1(n+2)(n+1) > 0

Знаменатель положителен при n ⩾ 0, значит разность положительна и suite строго возрастает.

Exercice 4 · récurrence

u0 = 2, un+1 = 3un − 2.
Montrer que pour tout n, un = 3n + 1.

Решение

Initialisation. Pour n = 0 : 30 + 1 = 1 + 1 = 2 = u0. ✓

Hérédité. Supposons que pour un entier n fixé, un = 3n + 1.

un+1 = 3un − 2 = 3(3n + 1) − 2
= 3n+1 + 3 − 2 = 3n+1 + 1 ✓

Conclusion. Формула верна для всех n ∈ ℕ.

Exercice 5 · limite

Déterminer lim un pour un = 2n² + 3n − 15n² + 4

Решение

При n → +∞ числитель и знаменатель оба → +∞. Это неопределённость «∞/∞» — выносим n²:

un = n²(2 + 3/n − 1/n²)n²(5 + 4/n²) = 2 + 3/n − 1/n²5 + 4/n²

Все дроби вида 1/n и 1/n² стремятся к нулю, значит:

lim un = 25
Exercice 6 · arithmético-géométrique

u0 = 1, un+1 = 0,8un + 2. On pose vn = un − 10.
a) Montrer que (vn) est géométrique.   b) En déduire un et sa limite.

Решение

a)

vn+1 = un+1 − 10 = 0,8un + 2 − 10
= 0,8un − 8 = 0,8(un − 10) = 0,8vn

Значит (vn) геометрическая с q = 0,8 и v0 = 1 − 10 = −9.

b) vn = −9 × 0,8n, следовательно:

un = 10 − 9 × 0,8n

Так как 0 < 0,8 < 1, то 0,8n → 0, значит lim un = 10.
